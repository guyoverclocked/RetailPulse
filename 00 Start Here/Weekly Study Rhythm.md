# Weekly Study Rhythm

## Why

The plan assumes classes, research, and other projects remain active. Consistency matters more than long weekend marathons.

## Default 5-7 hour week

- **Session A — 75 minutes:** learn the concept and write questions.
- **Session B — 90 minutes:** implement the smallest working slice.
- **Session C — 90 minutes:** test, debug, and record evidence.
- **Session D — 60 minutes:** integrate and update documentation.
- **Weekend option — 1-2 hours:** catch-up or deeper experiment.

## Minimum viable week

When overloaded, do one 90-minute build session and a 20-minute review. Preserve continuity; move unfinished work to the next recovery window.

## Rules

- One active build note at a time.
- Stop experiments with no written hypothesis.
- Protect the final holdout from curiosity.
- Commit small working changes.
- Keep one evening each week completely project-free.
